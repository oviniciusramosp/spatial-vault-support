Spatial Vault para Apple Vision Pro

Suporte

Ajuda para guardar seus arquivos e cuidar das suas cópias.

Read in English

Entre em contato

Escreva para hello@viniciusramos.com. Informe a versão do app, a versão de visionOS, o que você tentou fazer e a mensagem de erro, se houver.

Não envie seu padrão, chaves, conteúdo privado ou backup do cofre. Se enviar uma captura de tela, remova nomes e informações pessoais.

Abrir ou criar um cofre

Selecione os pontos na ordem do seu padrão. Para criar um cofre, use “Criar um novo cofre”, escolha pelo menos seis pontos distintos com uma mudança de direção e repita a sequência. Cada padrão abre apenas o cofre correspondente.

Importar e visualizar

Use “Importar” para escolher arquivos no seletor de Arquivos. Os originais permanecem onde estavam. Selecione um cartão para abrir a prévia de imagem, vídeo compatível ou texto. Outros formatos podem ser armazenados sem prévia.

Backup local

Com o cofre aberto, use “Backup” e salve o arquivo JSON cifrado em um local que você controla. Esse fluxo é uma exportação local, não sincronização nem backup automático do iCloud.

Para restaurar em uma instalação ou diretório sem esse cofre, selecione o padrão original na tela bloqueada e use “Restaurar backup local”. A restauração não sobrescreve cofres existentes. Preserve o arquivo original até conferir os dados restaurados.

Esqueci meu padrão

Esta versão não possui frase de recuperação independente. O backup também exige o padrão original. O suporte não mantém uma chave mestra e não pode recuperar um padrão esquecido.

Limites desta versão

  • Até 128 MiB por arquivo.
  • Backup de até 512 MiB; a biblioteca precisa caber nesse limite para ser exportada.
  • Sem iCloud automático, sync, compartilhamento, captura de câmera ou modo de coação.
  • O app bloqueia ao perder atividade. Não impede capturas de tela ou espelhamento.

Antes de apagar ou reinstalar

Confirme seu padrão, mantenha os originais e teste o backup. Desinstalar o app pode remover os cofres locais. Apagar um item do cofre não apaga cópias mantidas em backups ou no local de origem.

Support in English

Contact hello@viniciusramos.com with the app version, visionOS version, steps and error message. Never send your pattern, encryption keys, private files or vault backup.

Using your vault

The current interface is in Portuguese. Choose points in order to unlock. “Criar um novo cofre” creates a separate vault with at least six distinct points and a direction change. “Importar” opens the Files picker; originals remain in their original location. Image, supported video and text previews are available.

Backup and forgotten patterns

“Backup” exports an encrypted local JSON file. To restore on a clean installation or directory, enter the original pattern on the locked screen and select “Restaurar backup local”. Existing vaults are not overwritten. There is no independent recovery phrase; support cannot recover a forgotten pattern. Keep your original files and verify backups before reinstalling.

Current limits

128 MiB per file and 512 MiB per backup. No automatic iCloud backup, device sync, vault sharing, camera capture or duress mode. The app locks when inactive but does not prevent screenshots or mirroring.
